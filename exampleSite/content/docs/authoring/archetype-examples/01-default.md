This page was generated from the `default` archetype. The front matter is the minimum Hugo requires: `date`, `draft`, `title`. Nothing workshop-specific — no `time`, no `difficulty`, no `tags`.

Use this archetype when the page isn't part of a workshop. Examples: an *About* page, a contact form, a privacy policy, an internal index. Prose, links, and code blocks all work the same as on a workshop page; you just don't get the workshop-meta row up top because there are no workshop-meta keys in the front matter.

## Generated by

```bash
hugo new content/about.md
```

```toml
+++
```
