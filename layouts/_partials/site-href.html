{{- /* Resolve an href against the site baseURL, language-aware. Hugo's relURL preserves a leading "/" (treats it as domain-rooted), which breaks project pages where baseURL has a path prefix (e.g. GitHub Pages at https://owner.github.io/repo/). This helper strips the leading slash before piping through relLangURL so internal paths get the path prefix AND the current language prefix on multilingual sites with `defaultContentLanguageInSubdir = true`. Absolute/protocol-relative URIs (https:, mailto:, tel:, //cdn.example.com/...) and anchor (#) hrefs pass through unchanged. relLangURL degrades to relURL on single-language sites, so this is safe regardless of whether multilingual mode is configured. Usage: href="{{ partial "site-href.html" $someHref }}" */ -}} {{- $raw := . -}} {{- $out := $raw -}} {{- if $raw -}} {{- $hasScheme := gt (len (findRE `^[A-Za-z][A-Za-z0-9+.-]*:` $raw)) 0 -}} {{- if not (or $hasScheme (hasPrefix $raw "//") (hasPrefix $raw "#")) -}} {{- $out = (strings.TrimPrefix "/" $raw) | relLangURL -}} {{- end -}} {{- end -}} {{- return $out -}}
