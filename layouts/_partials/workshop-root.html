{{- /* workshop-root.html — given a page, return the section that scopes the workshop sidebar and the prev/next pager. The pager then DFS-walks this root's descendants, so prev/next flow across chapters within the workshop rather than dead-ending at chapter boundaries. Hub vs. workshop: - A "hub" is a section that exists for navigation only — its body is a card grid of children, not workshop content. Hubs do NOT render the sidebar shell; their layout is the same hero used on the language home. A page underneath a hub looks past it to find its workshop. - A "workshop" is a section whose own pages are content to be walked. It IS the workshop root: the sidebar tree is scoped to it, and the prev/next pager walks its descendants. How hubs are detected (top-down through the ancestor chain): 1. Explicit: front matter `hub: true` on the section. 2. Structural, depth-1 only: a section whose parent is the language home and which has no direct .md page children. This auto-detects the canonical `/en/ninja-workshops/` style top-level hub without requiring a marker on every existing site. The workshop root is the lowest non-hub section in the chain from the language home down to the current page (inclusive). If every candidate is a hub — i.e. the current page is itself a hub — return `false`, and the caller renders the hero layout with no sidebar. */ -}} {{- $page := . -}} {{- $root := false -}} {{- if and (not $page.IsHome) (ne $page.Kind "404") (ne $page.Kind "taxonomy") -}} {{- /* Candidate chain — bottom-up: page first, then each ancestor. `.Ancestors` stops at the language home (which we don't include). */ -}} {{- $candidates := slice $page | append $page.Ancestors -}} {{- /* Walk top-down (closest to language home first); the first non-hub is the workshop root. */ -}} {{- $found := false -}} {{- range $candidates | collections.Reverse -}} {{- if not $found -}} {{- $cand := . -}} {{- $isHub := eq ($cand.Params.hub | default false) true -}} {{- if and (not $isHub) $cand.Parent $cand.Parent.IsHome -}} {{- /* Depth-1 structural hub: parent is language home AND no direct .md page children. */ -}} {{- $hasDirectPages := false -}} {{- range where $cand.Pages "Kind" "page" -}} {{- if eq .Parent.RelPermalink $cand.RelPermalink -}} {{- $hasDirectPages = true -}} {{- end -}} {{- end -}} {{- if not $hasDirectPages -}}{{- $isHub = true -}}{{- end -}} {{- end -}} {{- if not $isHub -}} {{- $root = $cand -}} {{- $found = true -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- return $root -}}
