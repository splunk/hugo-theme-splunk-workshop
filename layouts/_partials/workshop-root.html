{{- /* workshop-root.html — given a page, return the section that scopes the workshop sidebar and the prev/next pager. The pager then DFS-walks this root's descendants, so prev/next flow across chapters within the workshop rather than dead-ending at chapter boundaries. Hub vs. workshop: - A "hub" is a section that exists for navigation only — its body is a card grid of children, not workshop content. Hubs do NOT render the sidebar shell; their layout is the same hero used on the language home. A page underneath a hub looks past it to find its workshop. - A "workshop" is a section whose own pages are content to be walked. It IS the workshop root: the sidebar tree is scoped to it, and the prev/next pager walks its descendants. How hubs are detected (top-down through the ancestor chain): 1. Explicit: front matter `hub: true` on the section. 2. Structural, depth-1 only: a section whose parent is the language home and which has no direct .md page children. This auto-detects the canonical top-level landing-page hub (one whose children are all sub-sections) without requiring a marker on existing sites. The workshop root is the HIGHEST (closest to the language home) section in the chain that is NOT a hub. We walk the chain top-down and return the first non-hub. If everything in the chain is a hub — i.e. the page is itself a hub — return false and the caller renders the hero layout. */ -}} {{- $page := . -}} {{- $root := false -}} {{- if and (not $page.IsHome) (ne $page.Kind "404") (ne $page.Kind "taxonomy") -}} {{- /* Candidate chain — bottom-up: page first, then each ancestor. `.Ancestors` stops at the language home (which we don't include). */ -}} {{- $candidates := slice $page | append $page.Ancestors -}} {{- $n := len $candidates -}} {{- /* Walk top-down by index — closest to the language home first. */ -}} {{- $found := false -}} {{- range seq $n -}} {{- if not $found -}} {{- /* seq is 1..n; we want indices n-1 down to 0. */ -}} {{- $cand := index $candidates (sub $n .) -}} {{- /* Skip the language home itself — `.Ancestors` includes it, but a language home is never a workshop root. */ -}} {{- if not $cand.IsHome -}} {{- $isHubExplicit := eq ($cand.Params.hub | default false) true -}} {{- $isHub := $isHubExplicit -}} {{- $isDepthOne := and $cand.Parent $cand.Parent.IsHome -}} {{- /* Compute direct .md children when needed: - depth-1 structural fallback (no explicit flag) - explicit-hub config-trap warning (any depth) */ -}} {{- if or $isHubExplicit $isDepthOne -}} {{- $hasDirectPages := false -}} {{- range where $cand.Pages "Kind" "page" -}} {{- if eq .Parent.RelPermalink $cand.RelPermalink -}} {{- $hasDirectPages = true -}} {{- end -}} {{- end -}} {{- /* Structural fallback: depth-1 + no explicit flag + no direct .md children. */ -}} {{- if and (not $isHubExplicit) $isDepthOne (not $hasDirectPages) -}} {{- $isHub = true -}} {{- end -}} {{- /* Config-trap warning: author marked the section `hub: true` but it also has direct .md page children. Those pages render at their URLs but become invisible in workshop nav (sidebar scopes past the hub, pager skips them). Dedupe via warnidf so the warning fires once per offending section across the whole build, not once per page render. */ -}} {{- if and $isHubExplicit $hasDirectPages -}} {{- warnidf (printf "workshop-root-hub-trap-%s" $cand.RelPermalink) "workshop-root: section %q has `hub: true` AND direct .md page children — those pages are unreachable in workshop navigation. Either remove `hub: true` from the section's front matter, or move the pages into a sub-section." $cand.RelPermalink -}} {{- end -}} {{- end -}} {{- if not $isHub -}} {{- $root = $cand -}} {{- $found = true -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- return $root -}}
