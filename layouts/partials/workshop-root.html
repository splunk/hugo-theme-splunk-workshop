{{- /* workshop-root.html — given a page, returns the Page that defines the navigation scope. Each section is treated as a self-contained nav unit: prev/next never cross section boundaries, so a chapter landing always starts the flow (no Previous wrapping back to the previous chapter). Rules: - Section page with child pages (chapter landing, workshop hub): scope = the page itself. - Section page with NO child pages (relearn-style "leaf section": a lesson directory that is just _index.md + an images/ bundle): scope = the parent section, so the leaf becomes one entry in a sibling-list pager rather than a stranded single page. - Regular page: scope = the page's CurrentSection. */ -}} {{- $page := . -}} {{- $root := $page.FirstSection -}} {{- if eq $page.Kind "section" -}} {{- if gt (len $page.Pages) 0 -}} {{- $root = $page -}} {{- else -}} {{- with $page.Parent -}}{{ $root = . }}{{- end -}} {{- end -}} {{- else -}} {{- with $page.CurrentSection -}}{{ $root = . }}{{- end -}} {{- end -}} {{- return $root -}}
